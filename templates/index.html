About AI Resume Analyzer

AI Resume Analyzer is an intelligent web application built using Machine Learning, Natural Language Processing and Flask. It helps students, freshers and professionals evaluate their resumes, predict suitable career roles, calculate ATS score, detect missing skills and compare resumes with job descriptions.

The project uses Python, Scikit-Learn, Flask, HTML, CSS and JavaScript to deliver fast and accurate resume analysis.

Frequently Asked Questions

Is my resume stored?

No. Your resume is processed only for analysis. It is not permanently stored.

Which file formats are supported?

Currently only PDF resumes are supported.

How is ATS score calculated?

ATS score is estimated using skills, resume sections, keyword matching, formatting and AI-based analysis.

Can I compare with any job description?

Yes. Paste any job description and the AI will calculate similarity and missing keywords.
