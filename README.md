# 🤖 AI Resume Analyzer

An AI-powered Resume Analysis System built using Machine Learning, NLP, and Flask.

The application analyzes resumes, predicts suitable career roles, calculates ATS compatibility, matches resumes with job descriptions, and generates an AI-based resume report.

---

## 🚀 Features

- 📄 Resume PDF Upload
- 🔍 Resume Text Extraction using PyPDF2
- 🤖 AI Career Prediction using Machine Learning
- 🛠 Skill Detection
- 📊 Resume Score Calculation
- 🎯 ATS Compatibility Score
- 💼 Job Description Matching using NLP (TF-IDF + Cosine Similarity)
- ✅ Matched & Missing Keywords Analysis
- 💡 AI Resume Improvement Suggestions
- 📥 Downloadable PDF Resume Analysis Report
